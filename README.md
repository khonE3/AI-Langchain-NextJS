# AI-Langchain-NextJS
AI Chatbot

## การติดตั้งโปรเจค Next.JS 15 ด้วย App Router

### 1. สร้างโปรเจคใหม่
```bash
npx create-next-app@latest
```

### 2. ระบุเวอร์ชันที่ต้องการ (15.5.2)
```bash
npx create-next-app@15.5.2
```

### 3. เปลี่ยน path เข้าไปยังโฟลเดอร์โปรเจค
```bash
cd ai-langchain-chatbot
```

### 4. รันโปรเจคในโหมด Development
```bash
npm run dev
```

### 5. Build โปรเจค
```bash
npm run build
```

### 6. รันโปรเจคในโหมด Production
```bash
npm start
```

## การกำหนดค่าเมื่อสร้างโปรเจค

เมื่อรันคำสั่ง `create-next-app` ระบบจะถามการตั้งค่าต่างๆ ดังนี้:

- **Project name**: ชื่อโปรเจค
- **TypeScript**: Yes
- **ESLint**: Yes
- **Tailwind CSS**: Yes
- **src/ directory**: Yes
- **App Router**: แนะนำให้เลือก Yes
- **App Router**: แนะนำให้เลือก No
- **Customize import alias**: No
